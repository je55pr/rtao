# PAL field-surface census

The retained evidence file `field-surface-census-2026-09-20.json` is generated by
`rtao/tests/fieldSurfaceCensus.pal.test.ts` from the developer-supplied European PAL MODE2/2352 image.
It contains no original game payload bytes.

The probe compiles collision from all 64 numeric `FLD/NNN.BIN` files plus Cloud Hill
`ACTION/A16.BIN`. For every source it records triangle counts and, for each low-nibble selector
that occurs, the population plus one original 32-bit surface word and its reflected render-space centroid.

The 64 standard FLDs reproduce the earlier static census exactly:

| selector | meaning | triangles | source count |
| ---: | --- | ---: | ---: |
| 0 | Dry | 65,095 | 22 |
| 1 | Off-road | 675,958 | 63 |
| 2 | Wet | 0 | 0 |
| 3 | Grass | 122,861 | 24 |
| 4 | Snow | 11,169 | 1 |
| 5 | Ice | 2,957 | 2 |

Cloud Hill adds 2,353 selector-0/Dry triangles and no other selector, bringing the combined Dry
population to 67,448. The JSON freezes the exact source occurrence sets for selectors 0..15.
Selectors 6..15 are absent from every field and special-outdoor source in this scope.

That absence must not be conflated with ordinary-race contact. Race car records have separately
recovered grip slots 6 and 7; those slots are outside this field-collision census and remain governed
by the race evidence/tests.

The census is collision-word evidence only. It does not infer surfaces from rendered textures,
material colour, minimap roads, or other visual heuristics. High bits of each representative
32-bit surface word are preserved verbatim instead of normalising the word to its low nibble.

Run the regression from `rtao` with the local PAL image:

```cmd
set "RTA_PAL_BIN=C:\path\to\Road Trip Adventure (Europe) (En,Fr,De).bin"
node_modules\.bin\vitest.cmd run tests\fieldSurfaceCensus.pal.test.ts --testTimeout=120000
```

To regenerate a candidate evidence file after the regression already passes, also set
`FIELD_SURFACE_CENSUS_OUTPUT` to the desired JSON path. The test compares current output with the
committed baseline before writing, so a decode regression cannot silently overwrite the oracle.
