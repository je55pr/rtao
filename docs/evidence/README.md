# Primary evidence

This tree retains evidence that is useful to reproduce or audit implementation claims: PAL instruction traces, scalar-oracle reports, deterministic validation logs and selected captures.

- `races/2026-09-05/` — current ordinary-race archaeology checkpoint evidence.
- `field-rendering/` — retained field/render probes from the outdoor reconstruction work.

Evidence files are intentionally less polished than `docs/archaeology/`: they preserve observations and generated outputs rather than presenting a final interpretation. Historical paths embedded inside old logs/patches are not rewritten.
