Road Trip Adventure PAL — live Peach -> Fuji seam probe
========================================================

Environment
-----------
.NET SDK 10.0.400
MonoGame DesktopGL 3.8.5
Xvfb + llvmpipe software OpenGL
Supplied PAL BIN/CUE

Command
-------
dotnet run -c Release --project src/Rta.Game -- --disc "/path/to/Road Trip Adventure.cue" --debug-fuji-route-seams

Probe sequence
--------------
The debug mode teleports Q62 40 m inside each known authored road boundary,
applies automatic forward throttle, and requires the actual WorldDrivingContext /
vehicle collision path to enter the expected neighbouring FLD without loading or
recreating the car.

Conclusion
----------
The authored route chain 223 -> 221 -> 220 -> 113 is valid not only in minimap
road geometry and render-edge heights, but in the current live vehicle/collision
runtime. This is strong evidence to freeze the canonical staggered topology and
move remaining world-map work toward presentation/global-scenery issues instead
of adding another sector transform.
